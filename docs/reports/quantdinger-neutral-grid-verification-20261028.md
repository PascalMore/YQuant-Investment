## 3. 五条实质结论

### 3.1 中性网格的价值在震荡/下跌市，不在单边上涨
OOS-early 期间 BTC 跌 15.14%，网格赚 1.60%，超额 +16.74pp。单边上涨期（OOS-late BTC +26.54%）网格赚 9.98% 但跑输 16.56pp —— 空头腿持续亏损。

### 3.2 杠杆不是收益放大器，是「网格宽度压缩器」
1x → -6.09%（夏普 -1.763）；3x → +5.63%；5x → +3.17%。杠杆放大名义仓位但绝对网格间距固定，可挂单数被压缩（交易数 75→30），有效工作区间变窄。想加杠杆必须同步放宽网格区间。

### 3.3 区间宽度比杠杆更关键
±1% → -6.17%（夏普 -1.107）；±3% → +5.63%；±5% → +2.65%。价格一旦跑出区间，网格退化为单向接刀。

### 3.4 网格密度存在最优值
n=6 → +1.80%；n=10 → +5.63%；n=20 → +4.02%（247 次交易，手续费 38.38 = n=10 的 2 倍）。网格过密 → 每次收割价差被手续费吃掉。

### 3.5 跨币种稳健，ETH 最优
ETH 是唯一跑赢基准的（超额 +0.91%），夏普 1.223、回撤 -3.33% 最小。BTC/SOL 被单边上涨拖累。

## 4. 资金费影响（回测引擎 `fundingMode=not_modeled` 的实际量级）

**判定**：对中性网格资金费影响约 0.2%–0.5% 本金量级，**不构成阻塞**。原因是网格 92.7% 时间空仓、多空对冲、持仓时间短。

**重要推论**：持续持仓的单向策略（DCA、马丁）资金费是**单向持续**侵蚀，与网格性质完全不同 —— 那两类必须单独做资金费敏感性分析，不能沿用本报告结论。

## 5. 局限与已知假象

1. **参数全为默认值**，非用户实盘配置 —— 本报告只证明「引擎正确 + 参数邻域有可解释结构」，不证明特定参数盈利。
2. **样本期偏单边上涨**（BTC +5.76%），对网格不利；OOS-early 下跌段更有参考价值但仅 3.5 个月。
3. **OOS-late 的 PF=103.91 / 胜率 100% 是小样本假象**：该区间价格几乎不穿越网格边界，配对几乎无滑点。真实网格 PF 预期 1.5–3。
4. **回测引擎不建模资金费**（上游限制，见 §4）。
5. **未建模其他实盘成本**：实际挂单排队优先级、交易所最小数量步进、部分成交概率。
6. **单币种单参数**，未做多币种同时运行的组合层面验证。
